Juego de cartas para parejas con Verdad, Reto y Prenda. Escalable en 3 niveles de intensidad.

## 🎮 [Jugar ahora](https://jh4m1l.github.io/cartas-del-deseo)

## ¿Qué incluye?
- 🃏 Mazo de 52 cartas real barajado al azar
- 🧠 Verdad, 🎯 Reto y 👗 Prenda como castigos
- 🎰 Doble Dare cuando salen cartas iguales
- 3 niveles: Chill, Caliente y Explícito
- Castigos editables desde cartas.json

## Tecnologías
- HTML · CSS · JavaScript · JSON
